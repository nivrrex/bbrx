# 效果证据

所有数字均来自**配对/并发对照**，判据在看数据之前写定。判读工具：`ab_pair.py`（真线配对短测）、
`flowlab`（按连接设 CC 的并发流）、`simlab`（netns+netem 仿真）、`ab_stuck.py`（卡死率统计判据）。

## 1. 仿真（netns+netem，206 ms RTT）

同 run 内乱序混跑多个变体（消除批次漂移）。每格：`基线 → bbrx`。

| 场景 | 中位 | 卡死率(<3M) |
|---|---|---|
| 20% 随机丢包，无瓶颈 | 4.30 → **18.05**（+320%，p=0.000） | **20% → 0%** |
| 14% 丢包 + 100M 限速器 | 27.49 → 26.76（n.s.） | 3% → **0%**；p10 13.48 → **22.15** |
| 多流 4 + 14% + 100M 限速器 | 75.57 → 78.65（**+4%，p=0.013**） | 0/0 |
| 100M 限速器 + 零丢包 | 66.25 → 67.42（+2%，p=0.034） | 0/0 |
| 0% 丢包（快线代表） | 126.20 → 126.46（**+0%**） | 0/0 |
| 8% 丢包 | 39.26 → 38.37（−2%，n.s.） | 0/0 |
| 突发丢包 ge:14:4 | 31.99 → 32.18（n.s.）；p10 4.31 → **13.41** | **20% → 4%** |

**七组场景零回归**；卡死场景收益最大，快线不受影响。

## 2. 真线 A：vps1（跨太平洋，峰时 20:51–21:55）

**方法一 `ab_pair`**（峰时配对短测，60 对，A/B 顺序随机）

| 臂 | 中位 | p10 | 卡死(<3M) |
|---|---|---|---|
| bbrplus | 9.15 | 0.83 | **17/60 = 28.3%** |
| **bbrx** | **15.91** | **6.84** | **0/60 = 0.0%** |

- 卡死率差 **−28.3pp**（Wald 95% ±11.4pp）
- Fisher 单侧 **p=0.0000**；配对不一致 17:0 ⇒ **McNemar 精确 p=0.0000**
- 全体均值比 **1.451**；非卡死流中位比 1.254
- 同会话噪声底（同臂 20 对）：卡死率差 **0.0pp**、McNemar p=1.000 ⇒ 该量可信

**方法二 `flowlab`**（按连接设 CC，不修改全局设置；180 流/臂）

| 臂 | n | 中位 | 卡死 |
|---|---|---|---|
| bbrplus | 179 | 7.69 | **36 (20.1%)** |
| **bbrx** | 180 | **9.13** | **1 (0.6%)** |

- 卡死率差 **−19.6pp**；Fisher **p=0.000**；流速率 Mann-Whitney p=0.000
- 轮内配对中位比 **1.223**（B 胜 39 / 负 21，符号检验 p=0.027）
- 事前方法自检（同臂 60 流/臂）：差 +5.0pp（门槛 <8pp）、Fisher p=0.677 ⇒ 方法有效
- **副产品**：同轮"既有卡死又有正常流"的轮数 观测 **27** ≈ 独立假设期望 **27.4**（59 轮）
  ⇒ **卡死是流内状态，与整条路径无关** —— 这正是"算法层面能治"的前提

## 3. 真线 B：vps2（30% 丢包、~40% 卡死率，ab_pair 30 对）

| 臂 | 卡死率 | 全体均值比 |
|---|---|---|
| bbrplus | 61.5% | — |
| **bbrx** | **13.3%**（McNemar 精确 p=0.0001） | **1.820** |

"双方都正常的配对"中位比 0.891（n=10，门槛 0.85）。

## 4. 判据（先于数据写定）

- 主判据（`ab_stuck.py`）：卡死率差 ≤ −10pp **且** Fisher 单侧 p<0.05；
- 防"牺牲正常流换卡死率"：**全体均值比 ≥0.95** **且** "双方都正常的配对"中位比 ≥0.85（n≥8）
  （不用"非卡死流中位比"——它有两臂各自剔除卡死流带来的**选择偏差**）；
- 样本不足判"**无结论**"，不判死；**单批不采信**，需两批独立复现。
